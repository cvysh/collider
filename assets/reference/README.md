# Reference material — not shipped, not committed

Mood boards, storyboards and visual references belong here for your own use
while designing.

**This directory is gitignored.** Reference images are frequently
third-party-owned, and a public repository is the wrong place for them even
when the use is private study. Keep them locally; commit only original work.

What *is* committed is `docs/design/DIRECTION.md`, which records the design
decisions derived from the references in words rather than in someone else's
pixels.
